# NAUX Learn 0.1.0

**Experimental Learning Release**

NAUX Learn is a deliberately small profile of NAUX for learning programming,
practicing data structures and algorithms, and writing experimental `.nx`
programs. It is a real open programming-language surface: examples and the
exercise corpus do not restrict how a learner may compose a valid program.

This release is not intended for production, security-critical or
safety-critical systems, stable API or long-term compatibility requirements,
or claims of native-performance leadership over C/C++.

Syntax, semantics, libraries, project formats, and installation behavior may
change substantially in future releases. Execution budgets reduce accidental
runaway computation; they do not form a security sandbox.

Learners do not need Rust or Cargo to install or run this artifact. The current
artifact is nevertheless produced by a Rust/Cargo seed and includes `egg` seed
debt. It has not reached seed independence, self-generation, or compiler
generation.

Future NAUX is intended to have a much broader scope than the Learn profile.
Research directions are not promises of specific features or delivery dates.

interactive disclosure can be reopened at any time with:
