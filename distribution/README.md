# NAUX distribution inputs

Distribution material is organized by scope, not by the identity of the whole
NAUX project.

- `s1-learn/` contains the reusable, sealed packaging inputs for Scope 1 —
  NAUX Learn.

The current `s1-learn` material defines the published NAUX Learn 0.1.2 Linux
experimental pre-release. Historical 0.1.1 release evidence remains under
`../archive/releases/0.1.1/` and is not reused as evidence for the minimal
0.1.2 payload.
