# NAUX distribution inputs

Distribution material is organized by scope, not by the identity of the whole
NAUX project.

- `s1-learn/` contains the reusable, sealed packaging inputs for Scope 1 —
  NAUX Learn.

The current `s1-learn` material records the withdrawn 0.1.1 implementation and
is not a public release. Historical notes and carrier acceptance evidence live
under `../archive/releases/0.1.1/`. A future release must update versioned
identity, usability gates, manifests, and scope-owned assets before packaging.
