# NAUX distribution inputs

Distribution material is organized by scope, not by the identity of the whole
NAUX project.

- `s1-learn/` contains the reusable, sealed packaging inputs for Scope 1 —
  NAUX Learn.

The current `s1-learn` material defines the NAUX Learn 0.1.3 Linux experimental
pre-release. The preceding 0.1.2 release remains identified by Git tag
`v0.1.2-learn`. Historical 0.1.1 release evidence remains under
`../archive/releases/0.1.1/`; neither prior release is reused as evidence for
the 0.1.3 payload.
