# NAUX distribution inputs

Distribution material is organized by scope, not by the identity of the whole
NAUX project.

- `s1-learn/` contains the reusable, sealed packaging inputs for Scope 1 —
  NAUX Learn.

The current `s1-learn` material is the tested Linux development candidate for
the next NAUX Learn release; it is not a public download. Historical 0.1.1
release evidence remains under `../archive/releases/0.1.1/` and is not reused
as evidence for the new minimal payload.
