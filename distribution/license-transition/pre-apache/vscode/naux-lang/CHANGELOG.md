# Changelog

## 0.1.2 — 2026-08-17

- Add source-validated snippets for ordinary NAUX blocks, input, output, and
  values.
- Remove the bundled file-icon theme. NAUX Language never changes the user's
  icon theme or injects an icon dependency; file-theme support is contributed
  independently through upstream theme projects.
- Make one dependency-free VSIX suitable for both Visual Studio Marketplace
  and Open VSX publication.

## 0.1.1 — 2026-08-17

- Prepare the first Visual Studio Marketplace preview.
- Keep `.nx`, `source.naux`, the NAUX icon, and 71 public builtins synchronized
  with the compiler surface.
- Exclude repository-only validation and Linguist-candidate files from VSIX
  packages.

## 0.1.0 — 2026-08-17

- Publish the canonical MIT-licensed TextMate grammar and Linguist candidate
  identity.
