# S4-WP5 non-claims

This package defines the required whole-program residual role. It does not
implement or admit that role and contains no executable residual artifact,
raw timing sample, latency, throughput, memory result, code-size comparison,
speedup, or performance result.

The accepted WP3 trace-native carrier remains
`naux-trace-carrier-observation`. Correct output alone cannot promote a trace,
precomputed checksum, copied reference loop, or handwritten native template to
`naux-residual`.

No comparison with C, C++, Rust, LLVM, or another implementation is authorized.
