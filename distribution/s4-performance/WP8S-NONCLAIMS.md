# S4-WP8S non-claims

WP8S admits one exact observation and nothing broader. It does not establish a
language-wide NAUX speedup, production performance, superiority over C, C++,
or any compiler, behavior on unmeasured workloads, or behavior on another
machine, operating system, toolchain, source commit, optimizer candidate, or
protocol.

The owner approval snapshot is a public, attributable GitHub Release record;
it is not represented as a cryptographic signature. The checker does not
download evidence, create claim text, create approval, or alter the release.
It only recognizes the fixed approval after the exact archive and receipt pass
WP8R, WP8N, and all four WP8O kernel gates.
