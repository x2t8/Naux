# S4-WP8E non-claims

WP8E admits deterministic candidate x86-64 function bytes and their structural
receipt only. It does not admit an ELF image, process execution, native-result
parity, timing, benchmark-role replacement, threshold evaluation, portability,
security, or a performance claim against C or any other implementation.

The frozen WP5D target remains the rollback artifact whenever any WP8E gate
fails. Candidate bytes must not be executed or measured under this authority.
