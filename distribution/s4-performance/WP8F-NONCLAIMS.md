# S4-WP8F non-claims

WP8F admits the deterministic structure of four ELF64 images represented as
hexadecimal report rows. It does not admit executable files, process execution,
native-result parity, timing, benchmark-role replacement, threshold evaluation,
portability, security, or a performance claim against C or any other system.

The frozen WP5D target remains the rollback artifact whenever any WP8F gate
fails. WP8F report bytes must not be executed or measured under this authority.
