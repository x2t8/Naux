# S4-WP8P non-claims

WP8P admits only a static claim protocol. It does not claim that an eligible
paired bundle exists, that the WP8O threshold passed on real evidence, or that
any performance statement has owner approval.

It does not authorize language-wide NAUX speed claims, comparisons with C or
C++, production-performance claims, unmeasured workloads, other hardware or
other operating systems. Synthetic fixtures and local green tests are not
measurements or public protocol acceptance.

This version has no bundle, candidate, request, approval, or admission input.
Resolving a blocker requires a later reviewed authority; a local edit cannot
unlock this protocol.
