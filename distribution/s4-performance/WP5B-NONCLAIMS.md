# S4-WP5B non-claims

The WP5B authority proves only that the frozen NAUX programs pass through one
ordinary frontend and one generic, deterministic, structurally verified
residual lowering.

It does **not** claim:

- that the residual IR is executable;
- that native machine code or an ELF artifact exists for this path;
- that the four checksum or process results have been replayed from residuals;
- that `naux-residual` is an admitted comparison role;
- any latency, throughput, speedup, parity, or leadership result;
- that static specialization may replace required dynamic traversal with an
  oracle or lookup.

Those statements remain forbidden until later authorities close machine-IR,
ELF, process, and measurement gates.
