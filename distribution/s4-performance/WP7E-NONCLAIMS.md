# S4-WP7E non-claims

WP7E admits only a static claim protocol. It does not claim:

- that the local WP5D–WP7D authorities have tracked public acceptance;
- that an eligible controlled-host bundle exists;
- that any synthetic candidate is a measurement;
- that any threshold has passed on real evidence;
- that NAUX beats C, C++, Rust, LLVM, or another implementation;
- production readiness, portability, sandboxing, seed independence, P2/P3,
  or Nauxogenesis.

This version has no claim-admission input path. Resolving a blocker requires a
new reviewed authority; editing a local candidate cannot unlock it.
