# Scope 4 benchmark authority: non-claims

This directory freezes the pre-measurement law for S4-WP1. It contains no
admitted timing result.

In particular, it does not establish that NAUX:

- is faster than C, C++, Rust, or any other language in general;
- meets either Scope 4 performance threshold on any kernel;
- has a complete or fair specialized baseline implementation yet;
- has claim-eligible hardware, toolchain, raw-sample, counter, memory, startup,
  compilation, specialization, or code-size evidence;
- can replace a kernel with a closed-form answer or precomputed output and
  present that result as generated-code performance;
- is production-ready, universally verified, self-originating, or independent
  of the current Rust/Cargo and `egg` seed debt.

Existing benchmark reports remain observations until a later accepted work
package produces evidence conforming to every frozen rule.
