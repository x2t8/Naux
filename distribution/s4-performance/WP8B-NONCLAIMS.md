# S4-WP8B non-claims

WP8B admits only a bounded transform contract. It does not admit transformed
machine code, prove a speedup, authorize a benchmark rerun, replace the first
WP7C bundle, change a threshold, or support a public performance claim.

The selected structural event count is not CPU-cycle attribution. The fixed
`r12` assignment is not a general register allocator and grants no portability,
production, sandbox, P2, P3, or Nauxogenesis authority.
