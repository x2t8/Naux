# S4-WP7A non-claims

WP7A admits only a clock-free evidence law. It does not claim:

- any observed runtime, latency, throughput, speedup, memory, or code size;
- that the current development host is controlled or retained;
- that a timing carrier or measurement runner exists;
- that external process elapsed time is the accepted runtime interval;
- that synthetic unit-test fixtures are benchmark observations;
- that a structurally valid evidence candidate passes variance or performance
  thresholds;
- C, C++, Rust, LLVM, or any other performance leadership;
- production readiness, portability, sandboxing, or toolchain sovereignty.

No WP7A path may call a clock, execute a benchmark, compile a role, or mutate
host configuration. Claim admission remains blocked by later authorities.
