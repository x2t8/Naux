# S4-WP7C non-claims

WP7C admits only the structure and refusal law of a controlled acquisition
runner. It does not claim:

- that the current development host is controlled or eligible;
- that a retained eligible host report exists;
- that any timing carrier has been executed by WP7C;
- that any warmup, raw sample, statistic, variance result, or threshold exists;
- that a compiler build cost or startup envelope has been observed;
- C, C++, Rust, LLVM, or any other performance leadership;
- production readiness, sandboxing, portability, seed independence, P2/P3, or
  Nauxogenesis.

Static CI must never invoke acquisition. Synthetic records used by tests are
not measurements and cannot be packaged as evidence.
