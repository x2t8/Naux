# Windows binary installation

[Tutorial index](README.md) · [Build from source](../README.md#build-from-source)

There is currently **no public NAUX Learn binary release for Windows**.

The earlier unsigned candidate was withdrawn together with the learner
release line. Its installer URL is intentionally unavailable. Do not disable
PowerShell or operating-system security policy to recover an old artifact.

A new Windows package will be documented only after native setup, interactive
terminal input, exact uninstall, and real Windows 10/11 acceptance all pass.
