# Linux binary installation

[Tutorial index](README.md) · [Build from source](../README.md#build-from-source)

There is currently **no public NAUX Learn binary release for Linux**.

The previous experimental prerelease was withdrawn after real-user testing
exposed incomplete interactive terminal input and an overly broad
learner-facing CLI. Its GitHub assets and installer URL are no longer
published. Do not reuse a cached one-command installer.

A replacement installer will be documented here only after the complete
install → write → run → keyboard-input → uninstall journey passes on a clean
supported host without author assistance.
