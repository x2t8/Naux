# NAUX implementation examples

These examples exercise the active `naux-lang` implementation.

- top-level `hello.nx`, `algo_*`, and `graph_*` files are ordinary language
  demonstrations;
- `bench_*` files are compiler/runtime measurement workloads, not learner
  tutorials;
- `competitive/` contains larger algorithm-library demonstrations;
- `smoke/` contains tiny parity and action fixtures used by repository tools.

The versioned learner exercises and deterministic input/output fixtures live
under `../learn/`. They remain separate because they are a release-gated
corpus rather than ad-hoc implementation examples.
