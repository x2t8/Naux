# NAUX Learn 0.1.1 — withdrawn

NAUX Learn 0.1.1 was withdrawn after real-user testing exposed incomplete
interactive terminal input and excessive learner-facing CLI complexity.

This directory preserves the exact release notes and accepted carrier
contracts for engineering history. It does not publish binaries or endorse
cached installers.
