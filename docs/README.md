# Documentation Index

This folder contains public technical documentation for the Naux workspace.

## Public Docs
- `compiler_pipeline.md`: frontend, IR, VM, JIT, and SSA pipeline overview.
- `phase1_proof_contract.md`: proof-gating contract for Refinement <-> SEFO.
- `language_spec.md`: current language surface and semantic rules.
- `stdlib_algo.md`: algorithm and graph stdlib coverage.
- `NAUX_COQ_MAPPING.md`: mapping between the Naux core subset and the Coq model.
- `naux-lang/docs/IR_SPEC.md`: crate-level IR spec used by `naux-lang`.

## Operator Docs
- `USAGE.md`: build, test, perf, and doctor commands.
- `PLAYBOOK.md`: local operator workflow.
- `PERF_FREEZE.md`: perf stabilization playbook.

Private planning notes and local benchmark reports are intentionally not listed here.
