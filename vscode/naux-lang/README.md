# Naux VS Code Extension (Local)

This is a local VS Code extension that provides:
- `.nx` language registration
- basic syntax highlighting
- the project-wide NAUX icon from `nauxlang.png`

## Install (Local)
1. Open VS Code.
2. Run **Extensions: Install from VSIX** is not required.
3. Use **Extensions: Install from Location...** and select `vscode/naux-lang`.
4. Choose **Naux Icons** as your File Icon Theme.

## Usage
- Open a `.nx` file and it will be recognized as `Naux`.
- The icon will show after selecting the **Naux Icons** theme.
