# NAUX asset ownership

Brand assets are scope-owned. Do not substitute one scope's identity for the
project-wide NAUX identity.

| Asset | Owner | Admitted use |
|---|---|---|
| `nauxlang.png` | NAUX project | Repository, website, language tooling, and project-wide identity |
| `langnaux-learn.png` | Scope 1 — NAUX Learn | Learn documentation, Linux bundles, and installer disclosure |
| `langnaux-learn.ico` | Scope 1 — NAUX Learn | Learn Windows executables, setup, and shortcuts |

Every future scope must introduce and seal its own assets. Scope assets must
not silently become the global NAUX logo.
